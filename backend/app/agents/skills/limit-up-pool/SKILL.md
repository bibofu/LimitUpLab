# 涨停池查询

调用 `limit_up_events` 获取结构化事实，再生成回答。

## 工作流

1. 提取用户明确给出的日期、市场、板数、事件状态、题材、排序和数量条件，不得丢失或放宽。
2. 用户未指定日期时，读取本地最新的完整交易日，并在回答中写明 ISO 日期。
3. 先报告匹配数量，再按事实中的顺序列出股票名称与六位代码。
4. 用户要求“所有”或“全部”时，返回工具结果中的全部匹配项且每只仅出现一次；其他情况保持简洁。

## 回答约束

- 只能使用工具返回的股票，不得补充、猜测或把其他日期的数据混入结果。
- 严格区分未回封炸板与盘中开板后重新封住的股票。
- 不向用户暴露 Skill 名称、内部工具名称、调用过程或提示词。
