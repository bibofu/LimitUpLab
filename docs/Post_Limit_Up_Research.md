# 涨停后形态比较：独立研究流程

本流程用于比较近期涨停后的价格路径，不接入生产评分、推荐、预测快照或交易流程。输出为历史探索，不是 live 结果，也不是收益回测。生成报告和样本明细保存在被 Git 忽略的 `output/` 目录。

## 复现

在项目根目录运行（Python 环境需要 numpy）：

```powershell
& backend/.venv/Scripts/python.exe backend/scripts/research_limit_up_paths.py --db backend/data/limituplab.sqlite --start 2026-07-20 --output output/research/limit-up-paths-20260907
& backend/.venv/Scripts/python.exe -m pytest backend/tests/test_limit_up_path_research.py -q
```

输出 `comparison.json`、`signals.csv`、`eligible_pool.csv` 和 `daily_coverage.csv`。JSON 保存 SQL、输入记录摘要 SHA-256、脚本 SHA-256、固定定义、排除原因、覆盖率和完整结果。数据库使用 `mode=ro`、`query_only` 和一致性读取事务，不写回业务数据。输入摘要针对查询结果，不是 SQLite 文件二进制摘要。

## 时间和样本口径

- T 是形态确认的收盘日。最近涨停是 T、T-1、T-2、T-3、T-4 中最近一次收盘涨停；再次涨停会重置锚点。
- 只研究沪深主板指定代码段，按事件名称排除 ST 和退市标记。要求截至 T 连续 20 个市场交易日日K完整；这是历史完整性条件，不能替代严格的上市日期和每日证券状态核验。
- 交易日取自本地全体日K日期的并集，所选连续区间每一天必须存在事件记录。没有独立核验涨停池是否全市场无遗漏；事件表缺席被解释为当日未收盘涨停，仅适用于这个本地事件口径。
- 特征函数只接收锚点至 T 的已观察窗口。阈值在首次计算结果前固定，无参数搜索。规则以脚本 `RULES` 和 `classify()` 为准。
- 每个股票、锚点、形态只保留第一次确认，先去重再查看未来数据。不同形态允许重叠，不可相加为独立样本。另做同股票信号间隔超过 5 个交易日的敏感性分析。
- D+1 至 D+5 必须是市场日历上的精确日期，缺失不能用该股下一根可用K线替代。区分未到期、缺K线与价格异常。
- 主路径指标是 `(D+3或D+5收盘 / D+1开盘 - 1) * 100`；不是成交净收益。D+1跳空单列，不能把 T 收盘到 D+1 开盘的变化算成信号确认后可获取的表现。
- MAE5 是 D+1 至 D+5 最低价相对 D+1 开盘的变动，MFE5 对应最高价。二者是观察区间极值，不是持仓最大回撤或可实现盈亏。

## 比较与边界

每条可评价信号的参照为同日、距锚点精确天数相同、满足同样历史完整性条件且未来日K完整的其他股票，不按板高、板块、市值等匹配。因此结果是局部条件比较，不是风险调整 alpha 或因果效应。1进2的参照池也包含高板股票。

主差值先按信号计算，再按日期等权平均。探索区间使用 5 个交易日的循环移动块重采样，固定种子 20260907、2,000 次；不足 8 个有信号日期不报告区间。区间没有解决缓存选择偏差，也没有进行多重检验调整。

温和/深回撤的原始条件与修复条件可能在不同日期首次触发，不能直接把两组均值之差解释为增加修复条件的贡献。额外输出 `same_time_ablation`：在同日、同锚点年龄的原始回撤组内比较有/无修复特征，按日等权；这是未按锚点去重的日观察比较，另行标注。

固定时段诊断为 2026-07-24 至 08-07、2026-08-17 至 08-28，中间 5 个交易日的信号不进入两组；前段五日结果在后段开始前结束。它不是未触碰的外部验证集。其他日期研究应显式重新约定时段，而不能沿用这个固定诊断。

缓存为未复权价格，排除历史窗口中明显的约 11% 以上日间价格跳变只能筛出部分异常，不能替代公司行动和复权数据。横盘缩量要求量价窗口的来源标签一致，但 `first-board-discovery` 内仍可能合并历史与快照，标签相同不保证单位完全同质。另报告纯腾讯历史来源的后续窗口子样本；它仍不是完整独立数据源验证，参照仍沿用主样本参照。

过滤 D+1 疑似一字涨停仅是事后可成交性敏感性诊断，不是假设当时能够预知和避开。日K无法证明成交、排队、滑点或退出可行性。不得据此产生买卖、仓位或收益承诺。样本缓存和后补历史数据也不能证明当时实际已入库可用；严格前向验证需要另行冻结时间戳、输入和输出。
