# 预测时间契约与历史样本审计

现行契约为 `prediction-time-v1`，数据库 Schema 为 11。所有窗口按 `Asia/Shanghai` 解释，09:30 不属于盘前固化窗口。

## 样本分组

`prediction_source=live` 为兼容旧数据保留，不能单独作为前向资格依据。使用公共函数 `assess_prediction_time` 判断阶段和资格。

| 分组 | 判断与用途 |
| --- | --- |
| `premarket_final` | 目标日 09:00 至 09:30 前固化，具有信息截止时间与交易日历证据；进入现行盘前终选前向评价 |
| `close_baseline` | 基准交易日当日 15:30 后生成的新收盘基线；单独研究，不计为盘前终选 |
| `legacy_close` | 没有新契约元数据，但在基准日收盘后生成的旧记录；按原评分版本独立研究 |
| `historical_backtest` | 历史补算；始终不计入前向样本 |
| `invalid_time` | 时区、固化窗口、信息截止或目标日历不满足要求；排除 |
| `retired_auction` | 已退役竞价实验；排除 |

旧版收盘记录缺少充分的输入采集时间证据，因此不能回填新契约元数据后声称它们属于现行盘前终选。早于 15:30 的旧收盘记录另标记 `before_data_readiness_gate`，保留为待核验的研究样本。

## 写入规则

- 直接日更脚本和定时日更共用同日收盘检查；本地最新日期如果是过去日期，补算只产生 `historical_backtest`。已有不合格原件不删除、不重新标成合格记录。
- 公共预测仓库再次验证时间，阻止直接调用仓库绕过日更入口。
- 盘前终选保存 `stage`、`version`、`target_trade_date`、`information_cutoff_at`、交易日历来源及日期列表。目标必须是基准日后的下一交易日，不能用工作日推算代替终选时的日历校验。
- 行情、人气、新闻发布时间与采集时间、财报采集时间等已记录的时间戳不得晚于信息截止时间。财报报告日期也不得晚于截止日期。数据源缺失仍通过原有 `data_missing` 和置信度机制表达。
- 终选提交前重新检查真实时钟。处理跨越开盘时，事务回滚，不能用处理开始时间掩盖晚到提交；刷新循环的后续重试进入原有 `missed_cutoff` 处理。
- 收盘基线转为终选时，原快照整行和逐股原始行先保存到追加式 `prediction_snapshot_archive`。归档、活动批次切换和完整终选写入同一事务；既有终选不能再次替换。普通刷新继续只更新草稿。

窗口校验证明记录满足已声明的时间契约，不代表已经独立证明每一条上游信息的历史可得性，更不代表评分有效性。

## 审计与复盘

在 `backend` 目录执行只读审计：

```powershell
.\.venv\Scripts\python.exe scripts\audit_prediction_times.py
```

添加审计标记：

```powershell
.\.venv\Scripts\python.exe scripts\audit_prediction_times.py --apply
```

`--apply` 先使用 SQLite 在线备份 API 创建一致性备份，再添加 `prediction_time_audits` 旁表记录。审计键包含原件内容哈希，重复执行不会重复追加同一结论；原预测、评分、名单和已保存复盘正文保持不变。默认报告与备份位于 `backend/data`，均被 Git 忽略。

受影响的旧复盘仍可追溯，摘要标为 `excluded`，不再展示其旧聚合指标。正常复盘接口按当前审计规则重算有效样本，不覆盖原报告。已核验报告的复用也要比较名单、分数、置信度、数据日期和样本阶段。

Review、Evaluation、Outcome 完整性和预测质量审计共用候选批次选择器。不合格的非竞价 `live` 日期整日排除，不用同日历史补算替代。退役竞价日期仍可作为明确标记的历史回测研究，不能进入现行前向统计。

质量审计接口：

- `benchmarks` 只统计符合新契约的盘前终选。
- `benchmark_cohorts` 按 `样本阶段/评分版本` 分开提供研究对照。
- `time_cohort_counts` 展示原始记录分组，`excluded_time_prediction_count` 展示排除行数。
- `strict_forward_prediction_count` 展示当前审计评分版本下的合格盘前终选数量。
- 旧字段 `data_as_of_violation_count` 为兼容保留，现为时间契约排除数的别名；不能再按日期字段大小解释。合法终选的 `data_as_of` 可以晚于基准交易日。

前端主复盘保持原有五日 Top10 卡片与汇总布局，每个日期只使用公共选择器确定的一份完整批次。若某个市场日没有通过时间审计的批次，观察窗口继续向前查找，不用同日历史补算替代，也不因此缩短为少于 5 张日期卡片。股票明细保留样本阶段与评分版本标记；严格前向质量审计仍只统计 `premarket_final`。

## 回归验收

重点覆盖同日收盘门槛、跨日补算、09:00/09:30 边界、UTC 与北京时间、周末和节假日日历、超截止证据、无历史补位、旧报告原件保留、终选不可重写与提交失败整批回滚。前端另验证切换分组时各项聚合指标不混入其他组。
