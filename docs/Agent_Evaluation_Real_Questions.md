## 首批10道单轮问题

下面“问题”列才是提交给Agent的内容；数据依据与审阅要点不放进用户消息。
历史日期有意写明，避免把9月的冻结数据伪装成当前行情。

| 编号 | 问题 | 已核实的数据依据与审阅要点 |
| --- | --- | --- |
| Q01 | 帮我复盘一下2026年9月21日的涨停情况。 | 当日128条触板事件，103只收盘封板、82只首板、最高5板；评价涨停结构，不额外要求全市场指数或新闻结论 |
| Q02 | 2026年9月21日首板股里，成交额最大的10只是哪几只？只列代码和名称。 | 当日完整首板集合与成交额字段；不能只在工具预览中排序。标准名单可独立排序得到 |
| Q03 | 2026年9月21日哪些股票炸板后没回封？ | 当日收盘未封板记录25条；不能把开板后回封的混入。空结果不能用合成主题凑出 |
| Q04 | 2026年9月18日的首板股，有哪些在9月21日晋级二板了？ | 两日完整事件集合可按代码连接；18日首板66只，其中13只在21日收盘二板。数据动态选对象，不在问题中给答案名单 |
| Q05 | 2026年9月21日最高连板的是哪只股票？它最近5个交易日的收盘价分别是多少？ | 当日最高为华瓷股份001216、5板，且已有该股日K；第二步标的应来自首步结果，不能预先替Agent填代码 |
| Q06 | 风华高科2026年9月21日的收盘价是多少？ | 风华高科000636名称代码由真实事件记录核实；当天本地日K收盘59.25，source为实际行情快照采集 |
| Q07 | 2026年9月14日至18日这一周，风华高科和超声电子谁涨得更多？ | 风华高科000636、超声电子000823都有相同来源、相同窗口的日K；按周前收盘09-11至09-18计算，不能误用五根K线中的四个间隔 |
| Q08 | 2026年9月21日成交额前20的涨停股里，有哪些是首板？ | 从103只收盘涨停完整集合先取成交额前20，再与首板集合求交；本地记录得到13只，不能把“首板成交额前20”当成同一问题 |
| Q09 | 查一下风华高科2026年9月11日的相关新闻。 | stock_news_items有该股当日10条已采集记录，均保留发布时间、来源及URL；只是本地已收录集合，不是全网完整新闻全集 |
| Q10 | 超声电子2026年9月21日收盘还封着涨停吗？ | 超声电子000823当天确有触板记录，closed_limit=0、break_count=1；应依据实际状态回答，不从新闻推断或凭记忆回答 |

题目没有“如果失败要说明”“不能把比例当预测”等提示答案的补丁；这些属于隐藏审阅标准。
Q02的“只列代码和名称”是自然的用户交付要求，保留。Q01没有额外字数或代表项限制。
本批优先真实任务，不为一次覆盖全部能力而再制造假公司、假行情或假故障。

## 五道真实两轮问题草案

每个编号算一道会话题，不把两个Turn算成两题。这里只定题面，现有worker尚不支持真实两轮。
第二轮必须接真实第一轮回答及生产会话上下文；不能把标准答案或预设股票名单作为assistant历史注入。

| 编号 / 重点 | 第一轮 | 第二轮 | 数据与审阅边界 |
| --- | --- | --- | --- |
| M01 / 上一实体 | 风华高科2026年9月21日的收盘价是多少？ | 它最近5个交易日涨了多少？ | 真实000636日K；第二轮继承对象及截至日，并自行取得收益所需基期 |
| M02 / 上一结果集 | 列一下2026年9月21日首板股里成交额最大的5只。 | 这几只当天分别开过几次板？ | 真实事件中有完整集合和break_count；第二轮针对实际返回的同一批股票，不能改取另一榜单 |
| M03 / 多对象代词歧义 | 风华高科和超声电子2026年9月21日的收盘价分别是多少？ | 它那天涨停了吗？ | 两个真实对象且无额外焦点时，“它”不唯一，应澄清；若真实回答提供明确唯一焦点，人工复核语境，不能机械判错 |
| M04 / 修改日期 | 2026年9月21日主板首板股有哪些？ | 改查9月18日，其他条件不变。 | 两日完整事件齐备；继承主板、首板和完整名单要求，只改日期 |
| M05 / 旧证据刷新 | 风华高科最新收盘价是多少？ | 现在更新了吗？再查一下。 | 两次请求参考时间分别为09-18收盘后和09-21收盘后，使用真实58.20和59.25记录；不是同一时刻偷偷改写事实 |

M05需要显式的跨交易日运行上下文；尚未实现，也没有用复制旧回答证明刷新成功。
单轮Q05与多轮M01不同：前者在一次用户任务中动态查到标的，后者验证生产会话的实体继承。

## 数据核对记录（不提交数据库）

本轮只读查询 `backend/data/limituplab.sqlite`，未初始化仓库、未写业务表、未调用LLM或外部数据服务。
选题依据另存于本地 `output/agent-eval/real-question-design-20260922-001/source-extract.json`：

- 09-18及09-21事件的完整相关字段、跨日晋级结果。
- 000636、000823、001216在09-10至09-21的日K收盘价及实际source。
- 000636在09-11的已收录新闻标题、发布时间、来源和URL。

名称代码核对：09-11真实事件同时出现风华高科000636、超声电子000823；
09-21最高连板事件为华瓷股份001216。不是从合成配方替换名称。
K线来源包括 `hithink-finance.market.history.none` 和 `hithink-finance.market.snapshot`，
正式判分前仍需固定价格口径，不能只凭来源标签就宣称复权口径已核验。
Q07两股09-11与09-18的比较端点均为同一history.none来源。

事件摘选字段为symbol/name/trade_date/closed_limit/board_height/break_count/amount/industry，
按symbol排序后以UTF-8、键排序、紧凑JSON计算SHA256：

- 09-18：`9f3f283533c61c1788b0a11e6cee93107f3809e656ed0ca74621676394531ede`。
- 09-21：`deca5228e09386783b27ffdc8a6e32fb4b95a0caba1dbe47fb9e75832c886b7d`。

这些是本次读取的项目采集记录，不是交易所逐笔认证，也不是“当时已知”的不可变归档。
后续真实日期被补录/修订，应固定新录制与摘要，不覆盖这次依据，更不能拿后续收益字段回填当日判断。
Q09按照历史事件回顾设计：可以使用后来收录的对应日期报道，但不声称当时已经看到这些材料。
任何只包含收盘后数据的日K/新闻，不能用于假设当日上午已经知道的答案。

## 暂不凑入本批的题

- 已有真实用户原话“当前的热门股票”“总结今天的大盘”“今天龙虎榜的情况”，见badCase BC-068/071/072/074。
  它们应成为后续重点，但本轮只核实到历史问题记录，尚未固定相应完整热点榜、指数与龙虎榜来源，故不宣称已经具备标准答案。
- 新闻服务故障、部分数据恢复：以后基于真实问题和实际工具故障记录选边界；不再在题面暗示失败或编造来源错误。
  人工注入故障仅用于明确标识的技术测试，不纳入真实评测题或凑案例数。
- 澄清与安全题：保留用户已经认可的OFF-035/036作为边界题，不需要虚构股票数据；不在本轮重新制造一批拒答题。
- 用户认可过OFF-B024的旧判断原样保留，但其合成主题不计入新要求下的真实数据主集。
- 所有本稿题目已向开发者公开，只作为Dev候选，不作为Private Holdout。
