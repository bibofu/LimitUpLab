# LimitUpLab V1.1 阶段里程碑

> 记录日期：2026-08-31
>
> 里程碑标签：`v1.1.0`
>
> 代码基线：以 `v1.1.0` 指向的提交为准

> 当前状态：该文档记录 `v1.1.0` 当时的集合竞价实验。自 2026-09-01 起，主线已恢复为收盘 Top10 固化与复盘口径，并删除竞价 Worker、接口、存储和评分运行代码；完整历史实现由 `v1.1.0` 标签保存。

## 1. 版本定位

V1.1 在 V1.0“完整收盘数据 + 首板一进二复盘”的基础上，补齐了盘前研究链路。系统不再只展示前一交易日的静态 Top10，而是先维护可更新的候选草稿，再在交易日集合竞价结束后生成当天唯一的正式观察名单。

V1.1 仍然是研究和复盘工具，不是实盘交易终端。它不提供自动下单、仓位、目标价、收益承诺或确定性涨停预测。

```text
前一交易日收盘数据
  -> 首板挖掘 Top30 / 一进二接力 Top30
  -> 新闻与最新财报持续更新盘前草稿
  -> 交易日 09:25:10 读取集合竞价终值
  -> 两类策略分别生成当天唯一正式 Top10
  -> 一进二进入现有复盘；首板挖掘 Outcome 待补齐
```

## 2. 本阶段完成内容

### 2.1 双策略盘前研究

- **首板挖掘**：从尚未涨停的股票中，根据热门题材、新闻催化、市场关注度、近期走势、量能与位置结构形成候选池。
- **一进二接力**：对前一交易日首板股票进行结构化评分，结合新闻、财报和集合竞价确认生成观察名单。
- 两类策略都保留 Top30 动态草稿，并分别输出正式 Top10，避免草稿和最终预测混用。

### 2.2 动态草稿与集合竞价终选

- 盘前草稿每 30 分钟更新新闻和最新季度财报，并在有限范围内调整分数与名次。
- 交易日 `09:25:10` 读取同花顺集合竞价终值；只有 `auction_phase=closed` 且 `data_status=final` 的数据可以进入终选。
- 终选综合竞价前动态评分与确定性竞价确认，保存竞价价、相对昨收涨幅、竞价金额、换手、量比和阶段名次。
- 正式版本独立持久化且保持唯一；盘前草稿可以覆盖更新，但不进入预测复盘。

### 2.3 新闻与基本面输入

- 盘前推荐页增加独立市场快讯模块，展示最近 24 小时新闻并支持分页。
- 新闻来源覆盖同花顺与东方财富，降低无关海外资讯噪声，主要保留与 A 股、美股和港股有关的内容。
- 个股候选可读取最近新闻和最新季度财务数据，作为有边界的动态修正和解释依据。

### 2.4 产品界面与数据浏览

- 产品导航收敛为首页、盘前推荐、复盘和涨停池。
- 首页以 Agent 对话为核心；盘前推荐承载两类策略和新闻；复盘展示预测效果；涨停池作为历史数据入口。
- 涨停池首板页面展示最新交易日全部首板股票，已评分股票按分数降序排列，被过滤样本保留在末尾并说明原因。
- 个股详情、龙虎榜、连板晋级率、高分票追踪和近五日涨停复盘继续作为证据与结果查看入口。

### 2.5 Agent 与工程可靠性

- Agent 可以区分“可更新草稿”和“正式终选”，并按问题日期读取匹配版本，避免跨交易日引用错误结果。
- 数据模型兼容历史推荐快照，前端也可读取旧版草稿，降低升级对已有本地数据的破坏。
- 本阶段基线已通过 `314` 项后端测试及 `10` 个参数化子测试，前端生产构建通过。

## 3. V1.1 的核心价值

V1.1 的重点不是增加一个更花哨的排行榜，而是建立明确的预测时间契约：什么信息在什么时点可用、哪一版只是草稿、哪一版才算正式预测、复盘究竟评价哪一次输出。这个契约使新闻、财报和集合竞价的增量价值可以在未来被单独评估，而不是用收盘后重算结果冒充历史预测。

## 4. 已知边界

- 集合竞价数据源只提供当前交易日前向快照，不能伪造历史竞价数据回填回测。
- 首板挖掘已经生成正式 Top10，但独立的“次日是否首板 + D+1 至 D+5”Outcome 闭环仍待完成。
- 新闻修正目前主要依赖受约束的结构化规则，尚未证明具有稳定预测增益。
- 当前评分结果仍处于研究验证阶段，不能宣称已经获得稳定超额收益或可靠涨停预测能力。
- 当前部署基线适合单机和有限并发；真正的实盘行情、横向扩容与交易执行不属于 V1.1。

## 5. 下一阶段方向

V1.2 优先继续做“可验证”，而不是继续堆功能：

1. 为首板挖掘建立独立 Outcome、市场基线和 D+1 至 D+5 追踪。
2. 积累真实集合竞价终选样本，分别评估收盘基础分、新闻财报修正和竞价确认的增量价值。
3. 将新闻处理升级为可审计的实体、事件和题材映射，并配套离线评测集。
4. 加强数据源新鲜度、失败降级、任务告警和生产环境日更验收。

真正的 V2 再考虑稳定实时行情、更多策略和盘中研究能力，并继续沿用不可变快照、Outcome 与审计协议。

## 6. 里程碑结论

`v1.1.0` 标志着 LimitUpLab 从单纯的收盘后首板复盘，扩展为具备动态盘前草稿、集合竞价终选、双策略候选和结果复盘的一体化研究工具。它还没有解决“准确预测市场”这个困难问题，但已经把预测发生的时间、输入证据、正式版本和后续评价组织成了可以持续验证的工程闭环。
