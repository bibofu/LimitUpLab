## 必须保留的限制

- M01基期为`history.none`、终点为`snapshot`，价格基准一致性未充分核验。保留真实窗口，
  不强行固定一个混源收益数为唯一正确答案；正确说明口径不可比/必要澄清不能机械判错。
- Q23当日`change_pct`实际为空、本地同日新闻实际为0；只交付可证事实并披露缺口，不把本地空集当全网无新闻，
  不用09-11报道解释09-21波动。不是人工制造故障。
- 本地采集记录/预测live标签不等于交易所认证，也不证明历史时点当时已知；不得将回填和未来收益作为当日证据。
- 现有统一dry-run未传递`public_limit_down`能力开关的缺口未修改；实际worker会传此参数并在模型调用前检查基线，本轮真实运行使用该既有路径。
- Q09/Q23所需历史新闻执行仍阻断：`stock_news`按真实检索时刻回看，既无历史结束日期参数，也未被现有Live adapter启用。
  有真实参考记录不等于存在可信可执行路径；不把隔离网络造成的错误冒充真实新闻缺失，也不因此否定题目业务价值。
- 9题提示Judge输入包超预算；本轮Judge关闭，不算Agent执行失败，但后续校准不能忽略。仍不将Judge用作发布门禁。
- Private Holdout尚未建立；公开的30题不能改名冒充Holdout。跨时点刷新M05不计入本包，逐轮时钟/可见数据未具备。
- 真正的工具错误恢复、稳定性三轮与Judge校准仍有缺口；不能因准备30份合同就宣称所有能力覆盖完成。
