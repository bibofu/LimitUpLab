## 1. 版本定位

V1.3 将 LimitUpLab 收敛为可解释、可审计的涨停后研究工作台：一进二接力、缩量整理和高位回撤并列展示，盘前候选的读取与正式前向样本资格分开判断，同时强化历史复盘、工具型 Agent 和统一工程验收。

相对 V1.2，本版本不再保留面向未涨停股票的低位挖掘运行链路；集合竞价实验仍维持退役。三个入口不代表三个已经验证有效的交易策略，也不代表它们共用一套预测排名、快照和 Outcome。

项目用于数据研究、Agent 工程实践和作品展示，不提供买卖指令、仓位、目标价或收益承诺。

## 2. 本阶段交付

### 2.1 三个并列研究入口

| 入口 | 当前行为 | 统计边界 |
| --- | --- | --- |
| 一进二接力 | 默认展示最新可用快照；最新记录为空且错过盘前固化时，可回退到此前可展示快照 | 展示可用不等于当日正式终选；前向资格另按预测时间契约审核 |
| 缩量整理 | 以最近收盘涨停为锚点，按固定价格区间、相对位置、成交量和完整性条件筛选 | 只读历史重算观察，不进入一进二前向统计 |
| 高位回撤 | 相对此轮涨停后、截至日前的局部参考高点，筛选回撤至少 10% 的形态 | “高位”为局部高点定义，不是长期高位或止跌确认 |

- 三个入口支持 URL 参数直达，缩量整理和高位回撤可查看历史截止日。
- 后两类有符合项时仅展示正式候选；没有符合项时，展示最多 6 个接近项，按未通过条件数量、归一化阈值距离、股票代码稳定排序。
- 接近项明确标记且不计入正式候选，不为凑数放宽规则；数据不足与有效空池分别解释。
- 缩量整理规则为 `consolidation_research_v0.2`，高位回撤规则为 `drawdown_research_v0.1`。具体阈值、日期与数据质量约束见 [策略第一版说明](Consolidation_Strategy_V1.md)。

### 2.2 预测时间契约与历史记录保护

- 引入 `prediction-time-v1`，区分盘前终选、收盘基线、旧版收盘记录、历史补算、不合格时间记录和退役竞价样本；不再仅凭 `prediction_source=live` 判断前向资格。
- 盘前终选限定于目标交易日北京时间 09:00 至 09:30 前，验证交易日历、信息截止时间及提交时钟；错过开盘不使用盘后信息补造终选。
- 收盘基线切换为正式终选时先归档原始记录，在同一事务内完成活动批次切换和终选写入；已有终选不能再次替换。
- 历史时间审计通过旁表保存结论，不改写原预测、评分、名单和已保存复盘正文。历史补算不能替代不合格 live 日期进入前向统计。
- 主复盘保留五日 Top10 布局，优先回放完整的已固化复盘快照；缺失日期按历史批次重建展示。严格前向审计与历史展示保持独立口径。

完整分类、归档与回放约束见 [预测时间契约](Prediction_Time_Contract.md)。V1.2 文档仅代表当时状态，不能替代此现行契约。

### 2.3 Agent 事实接地与可维护性

- 将大型对话编排中的提示词、模板、计划规范化、回答校验及工具执行拆分为职责明确的模块；工具执行按领域组织，以显式注册表分派。
- 每次请求独立保存执行状态；维持顺序执行、请求内评级复用、工具权限校验和失败降级，不让缓存跨请求串用。
- 增加统一工具数据结果语义、确定性回答事实校验、提示注入防护，以及产品多轮场景和题库执行器。
- 保留涨停后筛选、个股路径和历史统计的结构化研究工具。历史重算与探索性统计不作为实时推荐或策略有效性证明。
- 既有原生 Function Calling、Query Contract、滚动 Session Memory 和 SSE 继续提供规划、明确条件约束、会话连续性及流式回答。

### 2.4 研究、页面与工程质量

- 提供涨停后路径比较、回撤与整理匹配样本研究、缩量证据压力检查及近期案例导出；只读访问数据，记录输入摘要和覆盖情况，不将生成报告写入业务预测表。见 [独立研究流程](Post_Limit_Up_Research.md)。
- 个股详情支持五日分时展示，并优化行情缓存、预热及最新数据日期选择；复盘和聊天前端模块独立拆分。
- 删除已确认的未使用函数和导入；市场摘要与概览复用公共实现，规则评分和动态终选共用 A/B/C/D 分界，阈值仍为 80、65、50。
- 移除盘前页面重复的字段默认值处理，保留后端旧快照兼容；启用 TypeScript 未使用局部变量与参数检查。
- 本地和 CI 共用 `scripts/check_project.py`。CI 配置 Windows / Ubuntu 双平台验证；题库测试使用已入库的小型 fixture，不依赖开发者未跟踪的题库文件。

## 4. 已知边界与后续方向

- 评分和形态阈值尚未证明具有稳定预测能力；继续积累严格前向样本，按阶段和评分版本与确定性基线比较，不凭少量日期自动更改 Champion。
- 形态观察依赖本地事件和日 K 覆盖，未复权价格、成交量来源及历史证券状态核验仍有限制；历史首次符合日期不证明当时已入库或发布。
- 服务未在开盘前运行时，可展示已有快照，但不能据此宣称当天已形成有效盘前终选。完全没有可展示快照时仍需说明不可用状态。
- 后续优先补足数据覆盖与独立前向验证、持续扩展事实接地评估，再评估前端产物拆包与有限并发下的性能。
- 本里程碑不包含此前已撤回的双核心统一策略平台，也不宣称已交付三个策略共用的终选、快照和 Outcome 系统。

## 5. 里程碑结论

`v1.3.0` 标记了一个边界更清晰的研究版本：页面能区分正式候选与接近项，系统能区分可展示快照与合格前向样本，Agent 能以受控工具组织证据，工程侧具备统一、可重复的离线验证入口。它承诺可解释、可追踪和可复核，不承诺市场结果。
