## 裁判修改

- 结果顶层requested_date、data_as_of可核对请求与返回日期；failure_stage、network_request_sent、http_status可核对故障执行状态。data_as_of保留业务观察日期用途。行内或嵌套业务字段不会因同名获得执行证明权限。
- 各维度输出Schema只提供允许的target。运行时仍保留模型违反约束的原始断言及错误，不自动移维度、删引用或改判。
- 提示先区分来源身份、查询状态、实际预览和业务事实，再拆分原子断言、选择具体引用。整包或混合来源/状态的行不能替代业务字段；tool_label/synthetic不能单独证明来源或实际调用。
- 两阶段均区分“没有证据”与“存在相反证据”：部分空查询、缺故障原因或缺筛选执行记录保留未知；有明确反证才判矛盾。缺事实依据不能改称缺交付来绕过未知。
- 区分明确记录来源ID被改写与未知上游关系；自然语言同义描述仍可接受。不同ID不自动证明来源独立或共享。

没有新增题号特判、答案正则、隐式重试或自动修补模型判断。用途校验不能代替自然语言逻辑判断，提示词效果仍须用新模型输出验证。
